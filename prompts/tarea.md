# Tarea: Mi prompt profesional

## Funcionalidad elegida

La funcionalidad que tendrá mi prompt profesional es teniendo en cuenta los componentes tratados en el laboratorio 6.

## Version 1: prompt basico

```text
Actua como un desarrollador. Crea un programa CRUD
```

## Version 2

```text
Actua como un desarrollador. Crea un programa CRUD con la finalidad de gestionar productos de una tienda.
```

## Version 3

```text
Actua como desarrollador. Crea un programa CRUD con la finalidad de gestionar productos de una tienda para gestionar los productos de una tienda usando buenas prácticas.
```

## prompt final

```text
Actua como desarrollador. Crea un programa CRUD con la finalidad de gestionar productos de una tienda para gestionar los productos de una tienda de abarrotes, usando buenas prácticas. Explica primero la estructura del código y luego presenta el código. Ten en cuenta que no uses librerías externas.
```

## Evaluacion del resultado

El resultado que da la I.A al darle el último prompt se nota que lo que te devuelve la I.A es mucho más completa y comprensible y te ayuda a modificar y entender más fácilmente lo que devolvió.

## Errores que evite

```
Para evitar los errores clásicas como por ejemplo ser muy general en el prompt lo que ahora tomo en cuenta a la hora de elaborar un prompt es tomar en cuenta los componentes como el rol, instrucción, contexto y ejemplo.
```
